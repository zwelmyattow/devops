This repository contains the practical lab exercises (Labs 1 through 10) completed as part of my DevOps coursework. These structured labs demonstrate hands-on experience with modern software engineering, containerization, version control, and CI/CD deployment methodologies.

### 🛠️ Topics & Technologies Covered
Throughout Labs 1–10, this repository tracks practical configurations for:
- **Version Control & Project Governance:** Git workflows (`master`, `develop`, feature/bugfix branches), sub-modules, Issue/PR templates, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, and `SECURITY.md`.
- **Java & Spring Boot Integration:** Building a MySQL employee reporting system and RESTful web API packaged with **Maven** (`Java 17` & `Spring Boot 2.7.18`).
- **Containerization:** Multi-container orchestration using **Docker** and **Docker Compose** for the Java application and MySQL database.
- **Automated Testing & Code Coverage:** Unit testing and Dockerized database integration testing with **JUnit 5**, **JaCoCo**, and **Codecov**.
- **CI/CD Automation:** **GitHub Actions** pipelines for automated testing, JAR release packaging, and Markdown report deployment to **GitHub Pages**.
- **Static Code Analysis:** Code quality auditing and refactoring using **PMD** (Programming Mistake Detector) in IntelliJ IDEA.

### 📋 About the Repository
This serves as a living log of my progression through the DevOps curriculum, moving from basic Java and Docker environment setup in Lab 1 to full CI/CD release automation, web deployment, and static code quality checks in Lab 10.
