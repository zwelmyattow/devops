# ☁️ DevOps Labs: 1 to 10

**DevOps Practical Coursework | Edinburgh Napier University**

This repository contains the practical lab exercises (Labs 1 through 10) completed as part of my DevOps coursework. These structured labs demonstrate hands-on experience with modern infrastructure, version control, and deployment methodologies.

### 🛠️ Topics & Technologies Covered
Throughout Labs 1-10, this repository tracks practical configurations for:
* **Version Control:** Advanced Git workflows, branch management, and conflict resolution.
* **Containerization:** Building, running, and managing images using **Docker**.
* **CI/CD Automation:** Setting up automated build and test pipelines.
* **Java Integration:** Managing deployment lifecycles for Java-based applications.

### 📋 About the Repository
This serves as a living log of my progression through the DevOps curriculum, moving from basic environment setup in Lab 1 to complex deployment automation in Lab 10.
